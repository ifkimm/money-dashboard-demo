# 💰 내 필요에 맞춰 직접 커스터마이징한 가계부 대시보드

기존의 가계부 앱들이 제 소비 패턴이나 자산 관리 방식에 맞지 않아, **Streamlit**을 이용해 저에게 꼭 필요한 기능들을 직접 구현하고 커스터마이징한 개인 가계부 대시보드 프로젝트입니다.

---

## 💡 개발 배경 및 커스터마이징 포인트

기존 상용 앱을 쓰면서 아쉬웠던 점들을 보완하기 위해 아래와 같은 커스터마이징을 직접 적용했습니다.

### 1. 지출 분석 및 자산 연산 흐름 분리 (예외 처리 필터)
* 모든 결제 수단의 지출을 일괄 합산하기보다, 전체 소비 분석에는 반영하되 본인의 실제 최종 '순 잔액(Balance)' 연산에서는 제외할 수 있는 예외 처리(Exclude) 필터 로직을 커스텀 설계하여 자산 분석의 정확도를 높였습니다.

### 2. 개인 맞춤형 지출 카테고리 구성
* 상용 서비스의 획일화된 분류 방식 대신, 개인의 소비 패턴을 밀착해서 추적하고 모니터링할 수 있도록 꼭 필요한 맞춤 카테고리(예: 교육비 등)를 코드 레벨에서 직접 추가했습니다.

### 3. Streamlit 새로고침(Rerun) UX 문제 해결
* Streamlit 기본 작동 방식 때문에 거래를 추가하거나 삭제한 직후 `st.rerun()`이 돌면 성공 알림창이 즉시 사라져 작업 완료 여부를 알기 어려웠습니다.
* 이를 해결하기 위해 `st.session_state`에 처리 결과를 임시 기록해두고, 화면이 다시 그려진(Rerun) 후에도 상단에 성공 안내가 정상적으로 노출되도록 개선했습니다.

### 4. 구글 스프레드시트 연동 & 로컬 오프라인 백업 (Hybrid)
* 모바일이나 외부에서도 구글 스프레드시트 앱으로 가계부를 바로 적을 수 있도록 `streamlit-gsheets` API를 연동했습니다.
* 연동 설정이 없는 오프라인 환경(포트폴리오 검증용 로컬 실행 등)에서는 자동으로 로컬의 `expense_data.csv` 및 `settings.json` 파일을 데이터베이스 삼아 무리 없이 작동하도록 Fallback 로직을 설계했습니다.

## 🛠️ 주요 기능

* **자산 그룹화**: 카드로 나가는 돈, 운영계좌 잔고, 저축/투자 자산을 한눈에 묶어서 모니터링
* **기초 자산 설정**: 각 계좌의 현재 잔액을 폼을 통해 간편하게 갱신
* **소비 패턴 시각화**: 카테고리별 지출 순위 바 차트 및 일자별 지출 추이 라인 차트 (Altair 라이브러리 사용)
* **내역 관리**: 잘못 등록한 거래는 메인 화면에서 간편하게 선택하여 즉시 삭제 가능

## 💻 실행 방법

### 1. 저장소 가져오기 및 이동
```bash
git clone https://github.com/사용자이름/money-dashboard-demo.git
cd money-dashboard-demo
```

### 2. 가상환경 세팅 및 의존 패키지 설치
```bash
python3 -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

pip install -r requirements.txt
```

### 3. 실행하기
```bash
streamlit run app.py
```
> **참고**: 별도의 구글 시트 연동 설정(`.streamlit/secrets.toml`)이 없어도, 동봉된 가상의 샘플 데이터(`expense_data.csv`)를 기반으로 로컬에서 대시보드가 정상 작동합니다.
