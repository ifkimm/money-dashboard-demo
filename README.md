# 💰 커스텀 가계부 대시보드

기존 가계부 앱들이 개인적인 소비 패턴이나 자산 관리 방식에 맞지 않아, **Streamlit**을 이용해 필요한 기능만 직접 구현한 개인 가계부 대시보드 프로젝트입니다.

---

## 💡 개발 배경 및 주요 고민

기존 상용 가계부 서비스를 쓰면서 아쉬웠던 점들을 보완하기 위해 아래 기능들을 직접 설계하고 구현했습니다.

### 1. 순 잔액(Balance) 연산 예외 처리 로직 추가
모든 지출을 일괄 합산하면 자산 흐름이 왜곡되는 경우가 있었습니다. 전체 소비 통계에는 반영하되, 실제 최종 '순 잔액' 연산에서는 제외할 수 있는 예외 처리(Exclude) 필터 로직을 설계하여 자산 분석의 정확도를 높였습니다.

### 2. 개인 맞춤형 지출 카테고리 구성
획일화된 분류 방식 대신, 내 소비 패턴을 직관적으로 모니터링할 수 있도록 코드 레벨에서 꼭 필요한 맞춤 카테고리(예: 교육비 등)를 직접 구성했습니다.

### 3. Streamlit 새로고침(Rerun) UX 이슈 해결
Streamlit은 데이터 추가/삭제 직후 `st.rerun()`이 돌면 성공 알림창이 즉시 사라져 작업 완료 여부를 확인하기 힘든 문제가 있었습니다. 이를 해결하기 위해 `st.session_state`에 처리 결과를 임시 저장해두고, 화면이 다시 그려진 후에도 상단에 성공 안내가 정상 노출되도록 개선했습니다.

### 4. 구글 시트 연동 및 로컬 오프라인 백업 (Hybrid)
외부에서도 모바일 구글 시트 앱으로 가계부를 기록할 수 있도록 `streamlit-gsheets` API를 연동했습니다. 동시에 연동 설정이 없는 오프라인 환경(로컬 실행 등)에서도 문제없이 작동하도록, 로컬의 `expense_data.csv` 및 `settings.json` 파일을 데이터베이스로 사용하는 Fallback 로직을 구현했습니다.

---

## 🛠️ 주요 기능

* **자산 그룹화:** 카드 대금, 운영계좌 잔고, 저축/투자 자산을 한눈에 묶어서 모니터링
* **기초 자산 설정:** 각 계좌의 현재 잔액을 입력 폼을 통해 간편하게 갱신
* **소비 패턴 시각화:** `Altair` 라이브러리를 활용한 카테고리별 지출 순위(Bar 차트) 및 일자별 지출 추이(Line 차트) 제공
* **내역 관리:** 잘못 등록한 거래 내역을 메인 화면에서 선택하여 즉시 삭제 가능

## 💻 실행 방법

### 1. 저장소 복사 및 이동
`git clone [https://github.com/ifkimm/money-dashboard-demo.git](https://github.com/ifimm/money-dashboard-demo.git)`
`cd money-dashboard-demo`

### 2. 가상환경 세팅 및 패키지 설치
`python3 -m venv venv`
`source venv/bin/activate`  # Windows 환경: `venv\Scripts\activate`
`pip install -r requirements.txt`

### 3. 실행하기
`streamlit run app.py`

---

> 📌 **참고:** 별도의 구글 시트 연동 설정(`.streamlit/secrets.toml`)이 없어도, 프로젝트에 포함된 샘플 데이터(`expense_data.csv`)를 기반으로 로컬에서 정상 작동합니다.
